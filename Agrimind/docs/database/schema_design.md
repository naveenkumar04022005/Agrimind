# Agrimind Database Architecture & Supabase Schema Design

This document details the production PostgreSQL database schema for the Agrimind AI platform.

---

## 🏛️ Schema Overview & Isolation Model

Agrimind implements **multi-tenant isolation using Row Level Security (RLS)** at the PostgreSQL engine level. Every table containing operational farm records enforces `auth.uid() = user_id`, guaranteeing that farmers and agronomists can only access their own data.

```text
auth.users (Supabase Auth)
  │
  ├── 1:1 ── profiles (Farmer Bio, Role, Location)
  │
  ├── 1:N ── farms (Location, Soil Type, Acreage)
  │            │
  │            ├── 1:N ── soil_data (N, P, K, pH, Moisture)
  │            │            └── 1:N ── crop_recommendations (ML Outputs)
  │            │
  │            ├── 1:N ── crop_cycles (Planting Dates, Yield)
  │            │            └── 1:N ── fertilizer_recommendations (Dosage)
  │            │
  │            ├── 1:N ── crop_health_reports (Vision Transformer Diagnostics)
  │            │
  │            └── 1:N ── weather_data (Open-Meteo Telemetry)
  │
  └── 1:N ── ai_conversations (Agronomy Consultation Threads)
               └── 1:N ── ai_messages (Chat Log)

crops (Universal Agricultural Reference Catalog + Custom Crops)
```

## 📊 Table Specifications

### 1. `profiles`
Linked 1:1 with `auth.users(id)` via foreign key cascade. Automatically populated via PostgreSQL trigger `on_auth_user_created` whenever a user signs up.
- **Columns**: `id (UUID PK)`, `full_name`, `email`, `phone_number`, `avatar_url`, `role`, `preferred_language`, `country`, `state`, `district`, `created_at`, `updated_at`.
- **Security**: RLS enforces `auth.uid() = id`.

### 2. `farms`
Represents landholdings owned and managed by a farmer.
- **Columns**: `id (UUID PK)`, `user_id (FK)`, `name`, `description`, `total_area_acres`, `latitude`, `longitude`, `elevation_meters`, `address`, `soil_type`, `irrigation_type`, `created_at`, `updated_at`.
- **Security**: RLS restricts `SELECT`, `INSERT`, `UPDATE`, `DELETE` to `auth.uid() = user_id`.

### 3. `soil_data`
Chemical soil test reports and IoT sensor readings.
- **Columns**: `id (UUID PK)`, `farm_id (FK)`, `user_id (FK)`, `test_date`, `sample_depth_cm`, `nitrogen_mg_kg` (N), `phosphorus_mg_kg` (P), `potassium_mg_kg` (K), `ph_level`, `organic_matter_pct`, `electrical_conductivity`, `moisture_pct`, `notes`, `created_at`, `updated_at`.
- **Security**: Bound to `user_id`.

### 4. `crops`
Master catalog of crop parameters (ideal temperature, rainfall, duration, soil pH).
- **Columns**: `id (UUID PK)`, `name`, `scientific_name`, `category`, `min/max_temperature_celsius`, `min/max_rainfall_mm`, `ideal_ph_min/max`, `growing_duration_days`, `ideal_nitrogen/phosphorus/potassium_mg_kg`, `is_system_standard`, `created_by (FK)`.
- **Security**: Public read for `is_system_standard = true` or `auth.uid() = created_by`. Mutations restricted to `auth.uid() = created_by`.

### 5. `crop_cycles`
Tracks seasonal planting life-cycles, developmental stages, and harvest yields.
- **Columns**: `id (UUID PK)`, `farm_id (FK)`, `crop_id (FK)`, `user_id (FK)`, `cycle_name`, `area_planted_acres`, `sowing_date`, `expected_harvest_date`, `actual_harvest_date`, `status` (planned, sown, growing, flowering, harvesting, completed, failed), `actual_yield_kg`, `notes`.

### 6. `crop_recommendations`
Inference outputs generated by Agrimind predictive ML models (`crop_service.py` / scikit-learn).
- **Columns**: `id (UUID PK)`, `farm_id (FK)`, `soil_data_id (FK)`, `user_id (FK)`, `recommended_crop_id (FK)`, `recommended_crop_name`, `confidence_score`, `alternatives (JSONB)`, `rationale`, `expected_yield_estimate_kg_acre`, `model_version`.

### 7. `fertilizer_recommendations`
Prescriptive fertilizer schedules and dosage calculations.
- **Columns**: `id (UUID PK)`, `farm_id (FK)`, `soil_data_id (FK)`, `crop_cycle_id (FK)`, `user_id (FK)`, `fertilizer_name`, `recommended_dosage_kg_acre`, `application_stage`, `instructions`, `deficiency_detected (JSONB)`.

### 8. `crop_health_reports`
Visual leaf disease detection records from Hugging Face Vision Transformers.
- **Columns**: `id (UUID PK)`, `farm_id (FK)`, `crop_id (FK)`, `crop_cycle_id (FK)`, `user_id (FK)`, `image_url`, `diagnosed_disease`, `severity` (healthy, low, moderate, severe, critical), `confidence_score`, `symptoms (TEXT[])`, `organic_treatment`, `chemical_treatment`, `preventive_measures`, `is_resolved`, `resolved_at`.

### 9. `weather_data`
Telemetry and forecast time-series from Open-Meteo.
- **Columns**: `id (UUID PK)`, `farm_id (FK)`, `user_id (FK)`, `recorded_at`, `forecast_type`, `temperature_celsius`, `humidity_percentage`, `precipitation_mm`, `precipitation_probability_pct`, `wind_speed_kmh`, `solar_radiation_w_m2`, `weather_code`, `weather_description`.

### 10. `ai_conversations` & `ai_messages`
Chat history between the farmer and the Agrimind AI Assistant.
- **`ai_conversations`**: `id (UUID PK)`, `user_id (FK)`, `farm_id (FK)`, `title`, `context_metadata (JSONB)`.
- **`ai_messages`**: `id (UUID PK)`, `conversation_id (FK)`, `user_id (FK)`, `role` (user, assistant, system), `content`, `attachments (JSONB)`, `tokens_used`.

|---|---|---|---|---|
| `profiles` | `id = auth.uid()` | `id = auth.uid()` | `id = auth.uid()` | Cascade from Auth |
| `farms` | `user_id = auth.uid()` | `user_id = auth.uid()` | `user_id = auth.uid()` | `user_id = auth.uid()` |
| `soil_data` | `user_id = auth.uid()` | `user_id = auth.uid()` | `user_id = auth.uid()` | `user_id = auth.uid()` |
| `crops` | `standard OR created_by` | `created_by = auth.uid()` | `created_by = auth.uid()` | `created_by = auth.uid()` |
| `crop_cycles` | `user_id = auth.uid()` | `user_id = auth.uid()` | `user_id = auth.uid()` | `user_id = auth.uid()` |

| `fertilizer_recommendations`| `user_id = auth.uid()` | `user_id = auth.uid()` | Disabled | `user_id = auth.uid()` |
